# Circadia

An interactive, mobile-first prototype for planning rest and recovery around rotating shifts. The screens follow the Circadia wireframes in Figma.

## Run locally

Open `index.html` in a browser. The prototype is dependency-free and stores its demo data in the browser on this device.

## Prototype flow

- Four-step onboarding for work pattern and adding a roster
- Today dashboard with a 24-hour sleep and shift overview
- Week and month schedule views, date selection, and an add-shift dialog
- Recovery mood check-in, sleep tracking, sleep trend chart, and optional period tracking
- Profile preferences with interactive reminder switches

The screens use sample data. Calendar, Apple Health/wearable, authentication, and server sync are not connected in this browser prototype.

## GitHub Pages

The site can be deployed from **Actions → Deploy Circadia prototype to GitHub Pages → Run workflow** after GitHub Pages is enabled for this repository. A GitHub Pages site is public to anyone with its URL, even when its source repository is private. Do not store private health data or credentials in the site.
